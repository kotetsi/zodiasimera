# Ζώδια Σήμερα (zodiasimera.com)

Ελληνικό site με ημερήσιες αστρολογικές προβλέψεις, χτισμένο από τις πραγματικές θέσεις των πλανητών. Στατικές σελίδες, χωρίς server και χωρίς κόστος: χτίζεται κάθε βράδυ με GitHub Actions και φιλοξενείται στο GitHub Pages.

## Τι περιέχει

- `src/ephemeris.js`: υπολογισμός θέσεων Ήλιου, Σελήνης, πλανητών και Βόρειου Δεσμού (στοιχεία JPL για τους πλανήτες, Meeus για τη Σελήνη), φάσεις Σελήνης, είσοδοι σε ζώδια, ανάδρομοι, όψεις. Ελέγχθηκε με τα στοιχεία του US Naval Observatory για το 2026 (φάσεις Σελήνης με απόκλιση περίπου ενός λεπτού).
- `src/content/`: όλα τα ελληνικά κείμενα (ζώδια, ημερήσια κείμενα ανά οίκο και πλανήτη, συμβατότητα).
- `src/horoscope.js`: γεννήτρια ημερήσιας πρόβλεψης ανά ζώδιο από τις θέσεις της ημέρας (ώρα Αθήνας).
- `src/site/`: πρότυπα σελίδων.
- `src/config.js`: όνομα site, domain, AdSense, Analytics, προϊόντα ανά ζώδιο. Ό,τι μένει κενό δεν εμφανίζεται.

## Σελίδες

Αρχική με τον ουρανό της ημέρας, 12 σελίδες ζωδίων (σήμερα και αύριο, χαρακτήρας), προσωπικό ωροσκόπιο, γενέθλιος χάρτης, συναστρία, θέσεις πλανητών και όψεις, εφημερίδα πλανητών 12 μηνών, ημερολόγιο Σελήνης, ανάδρομοι πλανήτες, πίνακας συμβατότητας με 78 σελίδες συνδυασμών, σελίδα «Σχετικά». Το προσωπικό ωροσκόπιο, ο χάρτης και η συναστρία υπολογίζονται στον browser του επισκέπτη.

## Χτίσιμο

```
node src/build.js            # για σήμερα
node src/build.js 2026-12-24 # για συγκεκριμένη ημέρα
```

Το αποτέλεσμα βγαίνει στο `dist/`. Δεν χρειάζεται `npm install`.

Οι σελίδες ετών και οι μήνες της εφημερίδας διατηρούνται ως αρχείο. Το πλήθος σελίδων αυξάνεται με το ημερήσιο αρχείο. Οι κοινοί κανόνες SEO βρίσκονται στο `src/site/seo.js` και η πλοήγηση του αρχείου στο `src/site/archive.js`.

Για έλεγχο τίτλων, περιγραφών, εσωτερικών links, sitemap και διατήρησης URLs στην αλλαγή έτους:

```
npm test
```

Λεπτομέρειες αλλαγών και περιορισμών: `docs/seo-changes.md`.

## Δημοσίευση

1. Νέο repository στο GitHub, ανέβασμα των αρχείων.
2. Settings → Pages → Source: GitHub Actions.
3. Το workflow `.github/workflows/build.yml` χτίζει και δημοσιεύει σε κάθε push και κάθε βράδυ στις 00:07 ώρα Ελλάδας.
4. Όταν υπάρξει domain: Settings → Pages → Custom domain, και συμπλήρωση `siteUrl` στο `src/config.js` (ενεργοποιεί sitemap και canonical).

## Πριν από το AdSense

- Πολιτική απορρήτου και σελίδα επικοινωνίας με τα στοιχεία της επιχείρησης.
- Διαχείριση συγκατάθεσης cookies (στην ΕΕ η Google απαιτεί πιστοποιημένο CMP).
- Συμπλήρωση `adsenseClient` στο `src/config.js`.
